# Nashei Studios

Estudio de juegos de Roblox. Hacemos juegos chicos, los sacamos rápido, medimos cómo les va y nos quedamos con lo que funciona.

## Cómo trabajamos

- Cada juego parte de una plantilla común, no desde cero.
- Un juego jugable en 7 a 10 días. Si después de traer gente no retiene, se cierra y lo aprendido pasa a la plantilla.
- Las tareas viven en GitHub Issues, las conversaciones en Discussions y los avisos entre personas y agentes en un tablero fijado.
